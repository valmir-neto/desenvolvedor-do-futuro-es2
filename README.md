# O Desenvolvedor do Futuro — Engenharia de Software II

Estudo comparativo exploratório entre IA assistiva (GitHub Copilot Ask) e agente (GitHub Copilot Agent), usando um gerenciador de tarefas em Python.

## Como executar

Requer Python 3, sem dependências externas. Entre em `ia_assistiva` ou `agente_ia` e execute:

```sh
python main.py
python -m unittest discover -s tests -v
```

## Resultados

As suítes originais foram reexecutadas na preparação deste repositório: 5/5 testes na abordagem assistiva e 9/9 no agente. As suítes são distintas; esses números não demonstram superioridade de qualidade. Consulte `REQUISITOS.md` e `REGISTRO.md` para o protocolo e registro original.

O estudo tem uma execução de desenvolvimento por abordagem. Testes padronizados e novas execuções são etapas futuras, não resultados já obtidos.
