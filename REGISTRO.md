# Registro do experimento
Experimento A — IA assistiva

Resultado: 5 de 5 testes aprovados.
Tempo adicional de depuração: aproximadamente 5 minutos.
Problema: nome incorreto do arquivo task_manager.py, inicialmente criado como task_menager.py.
Consequência: ModuleNotFoundError durante a execução dos testes.
Correção: renomeação manual do arquivo.
Intervenção humana: diagnóstico e correção do problema de importação.
Conclusão parcial: a IA auxiliou na geração do código, mas foi necessária intervenção humana para corrigir a estrutura do projeto e executar os testes com sucesso.
